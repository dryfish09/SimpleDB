📦 SimpleDB

⚡ Lightweight Archive

📋 About

SimpleDB is a minimal file archive system. Files stored here are available for direct download via permanent URLs.

📌 Files are fetched live from the GitHub repository.

⚠️ Your browser doesn't support local storage. Token and cache will only work for this session.

🔑 GitHub Token Management

Add a GitHub Personal Access Token to increase API rate limits from 60 to 5,000 requests per hour. Tokens are stored locally in your browser.

Status: No Token Using unauthenticated (60 req/hr)

🔑 Generate a token with public_repo scope (or no scopes for public repos). Your token is stored only in your browser's local storage.

📝 How to Add Files

  1. Place your file in the /files/ directory
  2. Commit and push to GitHub
  3. File becomes available at the URL above
  4. Refresh this page to see it in the list
